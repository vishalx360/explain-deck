Hear the explanation, not read it

Your agent turns an answer into a narrated deck that plays itself.

$ npx -y explain-deck@latest init

Needs Node 18 or newer. Then ask your agent /explain-deck.

A deck that plays itself

  1. It speaks one step.
  2. It lights what that step is about.
  3. It moves on when the audio ends.

Share it as a Claude artifact

Ask your agent to host the deck in an artifact and it publishes the one HTML file.

/explain-deck host this in an artifact

Elsewhere it is still one file: any static host, or an email.
